Guide des Nouveaux Arrivants (Onboarding)

Bienvenue sur le projet ! Ce guide est conçu pour vous aider à comprendre la solution, installer votre environnement et réaliser vos premières contributions.

La Solution : Pourquoi cette plateforme ?
💡
Contexte Métier et Technique

Cette application n'est pas qu'un simple site e-commerce. Il s'agit d'une Plateforme d'Apprentissage DevOps conçue pour démontrer les architectures modernes basées sur les microservices, la conteneurisation et l'orchestration. Elle permet de gérer des produits, des utilisateurs, des commandes et des notifications, tout en appliquant des standards stricts de sécurité et de scalabilité.

Étape 1 : Prérequis et Installation
🛠️ Outils Requis
  • Git : Pour le contrôle de version.
  • Docker & Docker Compose : (Obligatoire) Pour l'environnement local.
  • Node.js 18+ : Pour le développement et le debug local.
  • Minikube & kubectl : Si vous travaillez sur la partie Kubernetes.
📥 Premier Lancement
git clone <repo> ecommerce-platform cd ecommerce-platform cp .env.example .env docker-compose up -d
Étape 2 : Comprendre l'arborescence
📁 /services

Contient le code source Node.js des 5 microservices indépendants (api-gateway, user, product, order, notification).

📁 /kubernetes

Les manifestes K8s (déploiements, services, ingress) pour simuler un environnement de production.

📁 /scripts & /database

Scripts shell d'automatisation (CI/CD local) et les migrations SQL d'initialisation de PostgreSQL.

Étape 3 : Workflow de Développement

Comment contribuer ?

  • Branching : Créez une branche feature/nom-fonctionnalite ou bugfix/nom-bug à partir de main.
  • Développement Local : Vous pouvez lancer un service spécifique via npm run dev dans son dossier tout en laissant les autres tourner sur Docker Compose.
  • Tests : Vérifiez toujours que les tests passent et que le linter ne renvoie pas d'erreur avant de commit.
  • Pull Request : Soumettez votre PR pour revue. La CI automatique validera le build des images Docker.

Vue d'ensemble de la plateforme

Solution complète de commerce électronique basée sur une architecture microservices moderne.

🚀 Scalabilité

Chaque service scale indépendamment selon la charge. Kubernetes HPA prêt.

🔒 Sécurité

API Gateway JWT, Helmet.js, rate limiting Redis, CORS configuré, TLS 1.2+.

⚡ Performance

Cache Redis multi-niveaux (sessions 24h, produits 1h), requêtes DB optimisées.

📦 Fiabilité

Messaging async RabbitMQ, Dead Letter Queue, retry logic, health checks.

Services principaux
🚪 API Gateway :3000

Point d'entrée unique. Routing, auth JWT, rate limiting, CORS, logging centralisé.

👤 User Service :3002

Authentification, gestion des profils utilisateurs, permissions et rôles.

📦 Product Service :3001

Catalogue de produits, gestion d'inventaire, recherche Elasticsearch.

🛒 Order Service :3003

Création et gestion des commandes, historique, intégration paiements.

📧 Notification Service :3004

Emails, SMS, événements temps réel via RabbitMQ consumer.

🐘 PostgreSQL :5432

DB transactionnelle principale. Tables: users, products, orders, order_items.

Infrastructure
⚡ Redis :6379

Cache distribué, sessions, rate limiting tokens. Eviction LRU, 512 MB.

🐰 RabbitMQ :5672

Message broker async. Exchange topic orders.topic, DLQ configurée.

📮 MailHog :1025

Capture SMTP pour tests. UI de visualisation sur le port 8025.

Exploitation & Supervision

Guide de déploiement, monitoring, troubleshooting et maintenance.

Démarrage rapide — Docker Compose
# 1. Cloner le repository git clone <repository-url> ecommerce-platform cd ecommerce-platform # 2. Créer le fichier .env cp .env.example .env # 3. Lancer tous les services docker-compose up -d # 4. Vérifier l'état docker-compose ps # 5. Suivre les logs docker-compose logs -f api-gateway
⚠️
Prérequis
  • Docker Desktop 4.x ou Docker Engine + Compose plugin
  • 4 GB RAM minimum disponible pour Docker
  • Ports libres : 3000–3004, 5432, 5672, 6379, 1025, 8025, 15672
  • 10 GB d'espace disque
Déploiement — Kubernetes
# 1. Créer le namespace kubectl create namespace ecommerce # 2. Déployer dans l'ordre (dépendances d'abord) kubectl apply -f kubernetes/00-namespace-config.yaml kubectl apply -f kubernetes/01-postgres.yaml kubectl apply -f kubernetes/02-redis.yaml kubectl apply -f kubernetes/03-rabbitmq.yaml kubectl apply -f kubernetes/04-microservices.yaml kubectl apply -f kubernetes/05-api-gateway.yaml # 3. Vérifier le déploiement kubectl get pods -n ecommerce kubectl get svc -n ecommerce # 4. Accès local via port-forward kubectl port-forward -n ecommerce svc/api-gateway 3000:3000

Stack de Monitoring

En environnement Kubernetes, le cluster est instrumenté avec Prometheus pour la collecte de métriques et Grafana pour la visualisation. Les services exposent leurs métriques (CPU, mémoire, requêtes/sec) sur l'endpoint /metrics.

  • Accès au Dashboard Grafana : http://grafana.ecommerce.local (Identifiants dans Vault/Secrets K8s).
  • Alertmanager est configuré pour remonter les alertes critiques (Uptime < 99.5%, Error Rate > 1%) sur le canal Slack de l'équipe Ops.
Playbook de Réponse aux Incidents (Incident Response)
🔴 Niveau 1 : Indisponibilité API

Action immédiate : Vérifier les logs de l'API Gateway et le statut des pods Kubernetes. Redémarrer l'ingress si nécessaire.

🟠 Niveau 2 : Lenteur Base de données

Action immédiate : Analyser le pool de connexion (pg_stat_activity). Tuer les requêtes longues (idle in transaction). Vérifier l'usage CPU/RAM du nœud Postgres.

🔵 Niveau 3 : File d'attente pleine

Action immédiate : RabbitMQ alerte si la queue dépasse 1000 messages. Vérifier si le Notification Service a crashé ou s'il est bloqué (timeout SMTP).

Sécurité & Best Practices
🔐 Authentification & Autorisation

JWT tokens expiration 24h, refresh tokens, bcrypt pour les passwords, gestion des rôles.

🛡️ Transport & Réseau

HTTPS/TLS en production, SSL obligatoire sur les connexions DB, CORS whitelist domaines.

⚡ Rate Limiting

100 req/min par utilisateur via Redis + middleware. Protège contre les abus et DDoS applicatifs.

🔑 Secrets Management

Variables d'environnement pour les secrets. Utiliser Vault ou K8s Secrets en production.
